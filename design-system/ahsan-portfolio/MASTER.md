## Direction: "Ledger"

The subject is a senior full-stack engineer who ships banking, fintech and AI products. The visual
language borrows from the artifacts of that world: accounting ledger paper (pale green stock with
ruled lines), bank statements (aligned columns, tabular figures) and the accountant's double rule
under a total. Dark mode is the ink; light mode is the paper.

Boldness is spent in one place: the ruled, tabular "account summary" in the hero. Everything else is
quiet. Text never sits in cards. One accent, used only for links, the primary button and focus.

## Typography

- Display and headings: **Bricolage Grotesque** (variable; opsz 12–96, wght 200–800). H1 at opsz 96,
  wght 500–600, letter-spacing −0.02em, `text-wrap: balance`, max 20ch. Sentence case only.
- Body, UI and figures: **IBM Plex Sans** (variable; wght 100–700). 17px / 1.6 body.
  `font-variant-numeric: tabular-nums` inside every ledger component.
- Fallback stacks:
  - `"Bricolage Grotesque", "Helvetica Neue", Helvetica, Arial, sans-serif`
  - `"IBM Plex Sans", "Segoe UI", Roboto, "Helvetica Neue", Arial, sans-serif`
- Self-hosted via `@fontsource-variable/*` (woff2, latin subset, `font-display: swap`).
- Scale (base 17, ratio ≈ 1.25): 13 small · 15 ui · 17 body · 21 lead · 26 h3 · 33 h2 · 41 h1 (mobile)
  · `clamp(2.5rem, 1.5rem + 3.5vw, 4rem)` h1 (desktop).
- Measure: prose ≤ 68ch, hard cap 80ch.
- No monospace face anywhere. No all-caps labels. No single-word colour accents inside headlines.

## Spacing, radius, elevation

- Spacing scale (px): 4 8 12 16 24 32 48 64 96 128. Section rhythm: 64 (mobile) / 96 (desktop).
- Container: max 72rem; gutters 16 / 24 / 32 px at 375 / 768 / 1024+.
- Radius encodes hierarchy: `0` for ruled rows and rules; `4px` buttons, inputs, tags; `8px` project
  covers and the mobile menu panel; `9999px` avatar and theme toggle track only.
- Elevation: none in dark (surface steps instead). Light: 1px `--rule` borders instead of shadows.
  Single exception: mobile menu panel `0 8px 24px rgb(14 31 27 / 0.12)`.

## Motion

- One page-load moment: the hero ledger rows print in sequence (5 rows, 35 ms stagger, 140 ms each;
  last row settles at 280 ms). CSS keyframes, no JS.
- Everything else answers a user action: hover/focus colour (150 ms), `<details>` expand, mobile menu
  open/close (200 ms), form status change.
- `@media (prefers-reduced-motion: reduce)` removes all of the above (rows render instantly).
- No scroll-triggered reveals. No page transitions. No hover lift/scale on cards.

## Components (contract)

- Ledger row: 2-column grid (label 14rem / value), 1px `--rule` bottom; last row closes with a double
  rule (2 × 1px, 3px apart). Mobile: label stacks above value.
- Project card: a single `<a>` wrapping cover + text. Cover = tinted panel with one large figure or
  the project's initials in Bricolage; `image` prop swaps the panel for an `<img>` (16:9, lazy).
- Tags/chips: `flex flex-wrap gap-2`; each chip `whitespace-nowrap`; never a fixed-height row.
- Buttons: primary = solid `--accent` with `--bg` text; secondary = text link with underline on hover.
  Minimum 44 px tall. No arrows or chevrons in labels.
- Focus: `outline: 2px solid var(--accent); outline-offset: 2px` on every interactive element.
- Icons: lucide-react, 20 px, stroke 1.75, `aria-hidden` when beside text.

## Anti-patterns (hard constraints)

cream + serif + terracotta · near-black + acid accent · glass / gradient surfaces · identical rounded
card kit · ALL-CAPS eyebrows · middle-dot meta strings · "→" on buttons or links · numbered 01/02
markers · fade-up on every section · stat tiles (big number + small label) · brand-logo marquees ·
skill percentage bars · emoji as icons · hover-only affordances.
